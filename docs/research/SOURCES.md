## Reference research rules
Study high-level gameplay behavior and independently implement original mechanics. Do not import source code or assets from Shootr without explicit permission/license verification. A public GitHub repository alone does not establish a commercial reuse license. Earlier conversation descriptions of particular upgrades and formations are preliminary reference observations, not re-audited source facts in P000. If detailed reference research is requested later, record exact URL, commit hash, relevant behavior, confidence and date, and distinguish observation from inference. No clone is included.

Papercraft direction was suggested by the project owner after seeing a friend's art. No friend-provided image or asset was supplied or licensed; create original artwork. Record actual art reference links and permissions as they are collected, not invented citations.
